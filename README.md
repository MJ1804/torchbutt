# TorchButt — The Meme That Lights Your Behind

Inspired by the legendary Dick Butt meme tradition (K.C. Green, 2006).

A butt with a torch. Emerald flame. That's it. That's the meme.

**Live:** https://torchbutt.vercel.app

## Quick Start

```bash
# Deploy to Vercel
cd site && ./deploy.sh <vercel-token>

# Or manually
cd site && npx vercel deploy --prod --yes --token <token>
```
